# 📦 Delivery Helper

Калькулятор стоимости и сроков доставки посылок из Ростова-на-Дону по городам России. Проект доступен в двух вариантах: консольное приложение и Telegram-бот.

Проект основан на реальном опыте работы в логистике: при отправке посылок клиенты чаще всего спрашивают, **сколько это будет стоить** и **когда посылка придёт**. Программа отвечает на оба вопроса за секунду.

## Возможности

- расчёт стоимости по весу и расстоянию;
- расчёт срока доставки с учётом времени на сортировку;
- два тарифа: «эконом» и «экспресс»;
- проверка введённых данных: неизвестный город, неверный вес, неизвестный тариф;
- Telegram-бот с пошаговым сценарием и кнопками выбора;
- обработка распространённых текстовых запросов по правилам, например: «Сколько стоит отправить 3 кг в Сочи?»;
- команды `/start`, `/help`, `/cities`, `/cancel`;
- автоматические тесты;
- безопасное хранение токена Telegram в локальном `.env`.

## Telegram-бот

Бот поддерживает два режима расчёта:

- пошаговый режим: город → вес → тариф → результат;
- короткий текстовый запрос: `Сколько стоит отправить 3 кг в Сочи?`.

Для текстового режима бот использует понятные правила: извлекает число с единицей `кг`, находит город из справочника и распознаёт тариф «эконом» или «экспресс». Это оптимизированный rule-based подход без внешнего AI API. Более свободное понимание любых формулировок с помощью нейросети остаётся следующим этапом.

В пошаговом режиме вес можно писать `2,5` или `2.5`. После результата можно начать новый расчёт или завершить диалог. Бот работает через long polling и рассчитан на личную переписку с ним в Telegram.

### Команды

| Команда | Что делает |
|---|---|
| `/start` | Начать новый расчёт |
| `/help` | Показать краткую инструкцию |
| `/cities` | Показать поддерживаемые города |
| `/cancel` | Отменить текущий расчёт |

## Быстрый запуск

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/artemka87/delivery-helper.git
cd delivery-helper
```

### Консольная версия

Сторонние библиотеки не требуются:

```bash
python main.py
```

### Telegram-бот

1. Создай и активируй виртуальное окружение:

```bash
python -m venv .venv
.venv\Scripts\activate
```

2. Установи зависимости:

```bash
python -m pip install -r requirements.txt
```

3. Создай файл `.env` рядом с `telegram_bot.py`, скопировав `.env.example`. В `.env` вставь токен, который выдал BotFather:

```dotenv
TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
```

> Никогда не публикуй реальный токен. Файл `.env` уже исключён из Git.

4. Запусти бота:

```bash
python telegram_bot.py
```

5. Открой своего бота в Telegram и нажми **Start** или отправь `/start`.

## Как устроен расчёт

```text
стоимость = (200 + 40 × вес_кг + 15 × расстояние_км / 100) × коэффициент_тарифа
срок      = 1 день на сортировку + расстояние / (500 км в сутки × скорость_тарифа)
```

| Тариф | Цена | Скорость |
|---|---:|---:|
| эконом | × 1.0 | × 1 |
| экспресс | × 1.6 | × 2 |
