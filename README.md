# 📦 Delivery Helper

Калькулятор стоимости и сроков доставки посылок из Ростова-на-Дону по городам России.

Проект основан на моём реальном опыте работы в логистике: при отправке посылок клиенты
чаще всего спрашивают, **сколько это будет стоить** и **когда посылка придёт**.
Программа отвечает на оба вопроса за секунду.

## Возможности

- расчёт стоимости по весу и расстоянию;
- расчёт срока доставки с учётом времени на сортировку;
- два тарифа: «эконом» и «экспресс»;
- проверка введённых данных (неизвестный город, неверный вес, неизвестный тариф);
- автоматические тесты.

## Пример работы

```
=== Калькулятор доставки из Ростова-на-Дону ===
Город назначения: Москва
Вес посылки, кг: 2
Тариф (эконом/экспресс) [эконом]:

Москва (1070 км), 2.0 кг, тариф «эконом»
Стоимость: 441 руб.
Срок доставки: 4 дн.
```

## Как запустить

Нужен Python 3.10 или новее. Сторонние библиотеки не требуются.

```bash
git clone https://github.com/<ваш-логин>/delivery-helper.git
cd delivery-helper
python main.py
```

Запуск тестов:

```bash
python -m unittest -v
```

## Как устроен расчёт

```
стоимость = (200 + 40 × вес_кг + 15 × расстояние_км / 100) × коэффициент_тарифа
срок      = 1 день на сортировку + расстояние / (500 км в сутки × скорость_тарифа)
```

| Тариф    | Цена  | Скорость |
|----------|-------|----------|
| эконом   | × 1.0 | × 1      |
| экспресс | × 1.6 | × 2      |
